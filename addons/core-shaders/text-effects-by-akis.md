# Akis 的文字特效

{% hint style="warning" %}
* **使用了 `rendertype_text` 着色器，这意味着某些插件将无法正常工作（例如 MythicHud）**
{% endhint %}

## 文本特效着色器

这个着色器为你的服务器添加了鲜艳而动态的文本效果，让内容更具吸引力。目前，它提供以下效果：

* **无阴影**
* **彩虹**
* **摆动**
* **彩虹 + 摆动**
* **跳跃**
* **彩虹 + 跳跃**
* **闪烁**

请持续关注后续更新，我们将不断扩展可用的效果种类。\
文本动画是让服务器内容更生动、更令人兴奋的绝佳方式。

## 如何添加到 Nexo

* 从 [Modrinth](https://modrinth.com/resourcepack/text-effects-by-akis) 或 [Github](https://github.com/AkisYTB3/Text-Effects-by-Akis) 下载着色器
* 将文件放入 `Nexo/pack/external_packs`
* 运行 `/n rl` 或重启服务器
* 完成！

## 使用方法

* 复制你想要使用的效果对应的颜色代码
* 将其粘贴到你想要应用的位置
* 文本就会呈现对应的特效 :)

## 效果及其十六进制代码

| **效果**             | **Hex 颜色** |
| -------------------- | ------------- |
| **无阴影**           | `#4e5c24`     |

| **摆动**             | `#e6fffa`     |
| **彩虹 + 摆动**      | `#e6fbfe`     |
| **跳跃**             | `#e6fbfa`     |
| **彩虹 + 跳跃**      | `#e6f7fe`     |
| **闪烁**             | `#e6f7fa`     |
