# 🎯 碰撞箱

家具有两种核心类型：带有碰撞交互的和不带碰撞交互的。
碰撞型的碰撞箱是普通的屏障方块，而非实体的则是交互实体。
交互实体没有碰撞，但可以是任意宽度和高度，不像屏障那样只能是 1x1x1 方块。下面展示了如何使用这两种方式。

此外，还有另外两种带碰撞但具有额外功能的碰撞箱类型：潜影贝型和恶魂型。恶魂碰撞箱仅在 1.21.6+ 版本中可用。
