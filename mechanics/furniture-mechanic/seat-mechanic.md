# 🪑 座位机制

通过座位机制，你可以为家具添加可坐的位置。
座位的配置方式如下，使用 `x,y,z` 偏移量。

```yaml
myitem:
  Mechanics:
    furniture:
      seats:
        - 0,0.5,0
```
